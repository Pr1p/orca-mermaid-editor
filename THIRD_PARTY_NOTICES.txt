Third-party notices for Orca Mermaid Editor
===========================================

editor/index.html embeds a bundled build of the following packages. The build
is reproducible from source in this repository: `build-trim/build-trimmed.mjs`
(inputs and versions pinned by `build-trim/package-lock.json`), run through
`build.sh`. No third-party source file is modified or hidden; the bundle is
minified only to fit the plugin frame's inline-script requirement.

mermaid 11.4.1
-------------
License: MIT
Source: https://github.com/mermaid-js/mermaid (npm package `mermaid@11.4.1`)
Copyright (c) 2014-2022 Knut Sveidqvist and contributors

The build excludes several long-tail diagram types and KaTeX; see
`build-trim/build-trimmed.mjs` for the exclusion list and `build.sh` for how the
bundle is inlined.

esbuild 0.28.2 (build tool, not shipped)
---------------------------------------
License: MIT
Source: https://github.com/evanw/esbuild

The bundled output also contains code from mermaid's transitive dependencies
as resolved by the pinned lockfile above (for example dagre, d3 modules,
lodash modules, stylis, khroma, cytoscape), each under its own MIT license.
Their exact versions are recorded in `build-trim/package-lock.json`.
